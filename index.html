How the system works

A city’s water supply produces filled tankers. Households consume them through delivery requests.

01

Producer
City water tanks fill delivery tankers and place them in the shared buffer.

02

Bounded buffer
The dispatch pool has limited capacity. It can become full or run empty.

03

Consumer
Household requests take a tanker from the buffer for delivery.

⇉

Concurrent requests
Enable request arrivals to send several household requests into the queue together.

⚡

Race condition
Turn off synchronization and run both processes to see how concurrent access can cause conflicts.

QUICK GUIDE

How the message pipeline works

01

Producer
A sender publishes a chat message into the server queue.

02

Bounded queue
The FIFO buffer has limited slots. Producers wait when it is full.

03

Consumer
A recipient reads the oldest queued message. Consumers wait when it is empty.

⚡

Race condition
Disable synchronization, then publish and read at the same time to expose a lost update.
